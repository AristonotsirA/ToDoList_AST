# AI 할 일 플래너

할 일을 생각나는 대로 적으면 AI가 요약하고 우선순위를 매겨 날짜별 일정표로 정리해 주는 웹사이트입니다.

## 기능
- Gemini / OpenAI / Claude 중 골라서 사용 (모델 이름도 직접 변경 가능)
- 요약 + 우선순위(급함·보통·여유) 목록
- 날짜 탭 + 시간대별 타임라인, 완료 체크
- 결과·체크 상태는 브라우저에 저장되어 새로고침해도 유지
- 다크 모드, 작은 화면(폰 커버 화면) 대응

## 사용법
1. 오른쪽 위 **⚙ 설정**에서 AI 회사, API 키 입력 후 저장
2. 할 일 입력 → 기간·활동 시간 설정 → **AI로 일정 만들기**

## API 키 안내
- 키는 사용자의 브라우저(localStorage)에만 저장되고, 선택한 AI 회사 서버로만 직접 전송됩니다.
- 서버가 없는 정적 사이트(GitHub Pages)라서, 각 사용자가 자기 키를 넣어 쓰는 방식입니다.
